Changed:

- Display > Windows is one page in every layout, and the traces have three arrangements, chosen with **Traces** there
  and on Display: **Overlay** (every source on one graticule), **Stacked** (a lane each in one plot) and **Windows**
  (four separate waveform views numbered 1 to 4, each source in the window its number row names). The Layout and
  Density rows of the page are gone: Side by side, two windows, Split and Four no longer exist as choices that clashed
  with Overlay and Stacked. **Full screen**, **Strip** and **Lower** (the pane under the plot) stay, and the pane no
  longer takes the windows away (or Stacked the pane): Add > Plot and Add > Table leave the arrangement as it is. The
  plot's menu has **Four windows** too, and `:VIEW:TRACes` takes `WINDows`. A set-up written with two windows or the
  densities Split and Four reads as four windows and Scope. Host only so far; not yet checked on the unit
  ([Getting started](wiki/First-Steps.md)).
